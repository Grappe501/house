# The House Metaphor System

The House represents the systems we live inside:
- work
- money
- time
- education
- healthcare
- governance

The house is not evil.
The house is not sacred.
The house is *built*.

Metaphor rules:
- Renovation language only (repair, reinforce, redesign)
- No destruction metaphors
- Weight, beams, cracks, rooms, windows recur consistently
- The house holds everyone; no group is outside it

The metaphor is never explained to the reader.
They feel it.
