# Act I HTML Room Scaffold v1
Date: 2026-01-31

This overlay generates **Room 001–025** HTML placeholders and replaces/updates
`/data/rooms/manifest.json` to include those 25 Rooms with mood + word targets.

It is designed to drop into the Netlify root and work immediately with the House Reader.

## What you do next
1) Replace placeholder copy inside each Room with final prose.
2) Add optional `audio` paths in the manifest when audio files exist.
3) Add `data-def` and `data-dive` triggers as the deep-dive library grows.
