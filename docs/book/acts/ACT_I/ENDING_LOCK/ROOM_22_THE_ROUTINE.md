# Room 22 — The Routine

## Function (non-negotiable)
Introduce repetition as comfort, not constraint.

## Emotional design
- Entry: settled
- Exit: slightly dulled  
Time passes without the reader noticing.

## Symbol set
- Repeated actions
- Cyclical descriptions
- Familiar phrasing reused intentionally

**Meaning:** habit replaces decision

## Language constraints
**Allowed:** again, as usual, the same as before, nothing unexpected  
**Forbidden:** stuck, loop, cycle, trap

## Audio / silence
Repetition if audio exists; otherwise silence.

## Door logic
Door appears *after* routine completes. Placement feels logical, not dramatic.

## Exit condition
Reader thinks: “I’ve done this before.”

## Failure mode
No disruption. No escalation. No introduced choice.
