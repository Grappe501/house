# Act I — Chapter 01 (Rooms 001–005) MasterBuild

This folder is the **10× blueprint** for the first 5-room breathing cycle.

**What this is:** planning infrastructure that sits *above* prose.  
**What this is not:** the prose itself.

## How to use
1. Read `01_CH01_OVERVIEW.md` to re-enter intent and constraints.
2. Use the room blueprints (Rooms 001–005) while rewriting prose.
3. After each room is drafted, run the acceptance gates in `09_ACCEPTANCE_GATES.md`.
4. Only then update the HTML room files.
