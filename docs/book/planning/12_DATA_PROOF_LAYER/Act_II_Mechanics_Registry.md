# LEVEL 3 — ACT II MECHANICS REGISTRY

This registry translates **Act II narrative mechanics** into explicit, auditable system mechanics.
Each entry corresponds to one or more Act II rooms and feeds Level 2 pages and Level 3 tools.

---

## M1 — Incentive Load Path Routing
**Source Rooms:** 026, 027, 029, 046  
**Mechanic:** Incentives route stress and outcomes across domains.

### Description
Economic and governance systems allocate rewards and penalties that cause predictable behavior patterns. These patterns aggregate into persistent outcomes.

### Enforcement Vector
- Policy rules
- Pricing structures
- Access conditions

### Failure Mode
- Siloed reforms that shift stress rather than reduce it

### Measurement
- Cross-domain outcome correlation (housing, health, time)
- Incentive alignment index
