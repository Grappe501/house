Why this exists

Real data without exposing keys

We can connect the site to Census and BLS while keeping your API keys private. We do this with Netlify Functions:

  • Browser calls /api/...
  • Netlify function calls the upstream API using your secret environment variable
  • Function returns clean JSON back to the browser
Security rule: never put API keys in front-end JavaScript.
Set up in Netlify

Environment variables

In Netlify → Site settings → Environment variables:

  • CENSUS_API_KEY
  • BLS_API_KEY

Then deploy. Use the health endpoint to verify:

/api/health

Endpoints

What’s available in V51

  • Census proxy: /api/census
  • BLS proxy: /api/bls
  • Health check: /api/health
  • Sources scaffold: /api/sources

Examples:

/api/census?year=2023&dataset=acs/acs5&get=NAME,B19013_001E&for=us:1
/api/census?year=2023&dataset=acs/acs5&get=NAME,B19013_001E&for=state:05
POST /api/bls
{ "seriesid": ["CUUR0000SA0","LNS14000000"], "startyear":"2015", "endyear":"2025" }
