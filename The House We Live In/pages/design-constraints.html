Level 2 — Design Constraints

Act III foundation: buildability before belief. (v1 skeleton)

What this page is

A constraint-first rulebook for rebuilding governance: we name tradeoffs early so they don’t show up later as cracks.

Sequence (the carpentry rule)

  1. Start where the load is highest (cracks, collapse points, extraction hotspots).
  2. Move load paths before adding features.
  3. Lock against reset (durability) before declaring victory.
  4. Measure what changes (QOL) before expanding scope.
