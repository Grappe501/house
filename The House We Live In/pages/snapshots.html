Why

Snapshots turn assumptions into citeable artifacts

As the model grows, we need a way to:

  • freeze assumptions for a given result
  • share and cite model outputs publicly
  • avoid “moving targets”

Snapshots export the complete input state and computed outputs as a JSON file.

How

What gets exported

  • timestamp
  • geography + observed proxies (if present)
  • scenario preset + parameters
  • pillar parameters (when applicable)
  • computed outputs by horizon

Right now downloads are local-only. Later we can add “publish snapshot to git” workflow.
