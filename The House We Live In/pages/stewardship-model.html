Stewardship Model (Keys & Rotation)

Act IV anchors: Rooms 081–082 (Keys / Rotation). Supports Beam: Room 087 (Loophole Hunt).

What this is

Stewardship is authority without ownership. No one holds all the keys. Roles circulate. The system is designed to prevent permanent gatekeepers.

Core roles (v1)

  • Metrics Steward: runs drift scan; posts weekly status.
  • Log Steward: maintains audit log + patch notes.
  • Playbook Steward: runs incident-response steps when red.
  • Training Steward: keeps pipeline running; certifies maintainers.
  • Public Walkthrough Host: quarterly audit walkthrough facilitator.

Rotation rules (v1)

  • Steward roles rotate on a published schedule (default quarterly or semiannual).
  • No single person holds the same key indefinitely.
  • Rotation includes a handoff checklist and shadow period.
  • Random “spot audits” prevent back-channel control.

Anti-capture features

  • Role turnover reduces concentration.
  • Public artifacts (logs, status notes) reduce opacity.
  • Legible process means fewer “expert excuses.”
