WHY: a single score that can’t hide trade-offs

Readers need a way to see whether the system actually improves life for the working majority. The Quality of Life (QoL) Index is a composite score (0–100) that rolls up multiple dimensions.

Rule: every point in the index must be traceable to a proxy and a data file.

How scoring works

Transparent, auditable logic (scaffold)

  • Each dimension has a proxy and a weight (weights differ by band).
  • Scores are normalized between Status Quo and WMR for the selected horizon.
  • This first version uses simple, explainable proxies. Later versions will use validated indicators.
