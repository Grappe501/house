What this is

Budget Line Items (the engine behind “positive year”)

This page breaks the WMR fiscal model into explicit line items. Each item has:

  • a yearly ramp (how fast it phases in),
  • a low/base/high steady-state value,
  • and a note explaining what it represents.
Design rule: no hidden “magic savings.” If it affects the budget, it must appear here.

How this connects

From line items → surplus → allocation → debt paydown

  • Line items compute the primary balance improvement each year.
  • If the primary balance crosses into surplus, we allocate it by rule: Surplus Allocation Rules.
  • Debt paydown becomes mechanical and auditable: National Debt Paydown.
