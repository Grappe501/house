Assumptions

What drives these scores

Every pillar score is built from:

  • Observed indicators (when wired) — shown with source tags
  • Transform formula — explicit mapping to a score
  • Scenario parameters — targets that scale change over time
  • Phase curve — how change is phased (linear interpolation between anchors)

Many indicators are still placeholders. Housing + mobility can be grounded today via ACS distributions.
