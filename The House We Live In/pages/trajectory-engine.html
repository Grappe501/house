What this is

The Trajectory Engine

The site is evolving into a fully explainable forecasting system.

The trajectory engine is a JSON spec that defines:

  • Dimensions and weights
  • Observed baselines (ACS/BLS now; more later)
  • Transforms (how data becomes a score)
  • Scenario parameters (what changes how fast)
  • Phase curves (how progress unfolds over time)

File: /data/trajectories/trajectory_engine_v56.json

How to use it

Workflow

  1. Run Household Impact in observed mode to export local QoL proxies
  2. Open Scenario Panel to select targets
  3. Open QoL Timeline to see results + drivers
Household Impact
Exports rent/commute proxies in observed mode. Scenario Panel
Choose targets and store scenario locally. QoL Timeline
Computes results from engine + scenario + proxies.
Transparency rules

No hidden math

Every score must cite:

  • the indicator (table/series)
  • the transform formula
  • the scenario parameter
  • the phase curve

As we expand, each pillar will get the same engine-backed structure.
