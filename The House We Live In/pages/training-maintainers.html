Training the Maintainers

Act IV anchors: Room 083 (Training), Rooms 096–098 (Handoff / Manual). Beam: Room 098.

What this is

A pipeline that produces competent stewards. This is not motivational training—this is operational training: how to run cadence, logs, playbooks, and handoffs.

Curriculum (v1)

  1. Legibility: explain the system in plain language.
  2. Cadence: weekly scan, monthly review, quarterly walkthrough.
  3. Artifacts: status notes, patch notes, audit logs.
  4. Playbooks: what to do when red.
  5. Handoff: teach someone else to do it (manual + shadow period).

Certification (v1)

  • Complete training modules
  • Shadow an active steward for one cycle
  • Run one cycle under supervision
  • Publish your first artifact (status note or patch note)
