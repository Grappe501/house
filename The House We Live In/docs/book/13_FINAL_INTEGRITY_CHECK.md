# Final Integrity Check (v11)

Use this checklist before writing and before publication.

---

## Ideology Neutrality
- [ ] No party names
- [ ] No ideological labels
- [ ] No culture-war language
- [ ] No demonization

## Emotional Safety
- [ ] No shame triggers
- [ ] No urgency panic
- [ ] No fear-based motivation
- [ ] No superiority tone

## Metaphor Consistency
- [ ] House appears only in approved chapters
- [ ] Weight evolves correctly
- [ ] Machine is explanatory, not accusatory
- [ ] Circulation is human-centered

## Reader Journey
- [ ] Recognition before explanation
- [ ] Explanation before solution
- [ ] Solution before action
- [ ] Action without pressure

## Website Contract
- [ ] Deep mechanics deferred to site
- [ ] Book remains readable in one sitting
- [ ] Hyperlinks enhance, not distract

---

## If all boxes are checked:
You are ready to write.
