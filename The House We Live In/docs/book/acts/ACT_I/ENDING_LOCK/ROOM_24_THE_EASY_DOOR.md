# Room 24 — The Easy Door

## Function (non-negotiable)
Introduce conditional freedom without force.

## Emotional design
- Entry: open
- Exit: uneasy  
First conscious discomfort.

## Symbol set
- One clear path
- Other paths vaguely referenced
- Ease contrasted with ambiguity

**Meaning:** freedom shaped by friction

## Language constraints
**Allowed:** simple, efficient, straightforward, most people choose  
**Forbidden:** blocked, closed, not allowed

## Audio / silence
Neutral. Slight narrowing of soundscape if used.

## Door logic
One door is obvious. Others exist only conceptually.

## Exit condition
Reader realizes: “I wasn’t forced. I was guided.”

## Failure mode
No coercion implication. No moralizing. No heroic resistance framing.
