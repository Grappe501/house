# Act IV Room Beat Sheet (Template) — Rooms 076–100

For each room include:
- Beat (1–2 sentences)
- Mode (Compression / Flow / Beam / Silence)
- Primary symbol (calendar, porch light, logbook, keys, gutters, patch notes)
- Mechanic (drift detection, audit, rotation, training, incident response)
- Door Line (must point to Level 2/3 maintenance pages/tools)
- Targets (URLs)

Guidance:
- Act IV should feel calm, competent, and unafraid of repetition.
- Beam rooms define how the system survives success.
- Silence rooms restore trust and reduce vigilance fatigue.
