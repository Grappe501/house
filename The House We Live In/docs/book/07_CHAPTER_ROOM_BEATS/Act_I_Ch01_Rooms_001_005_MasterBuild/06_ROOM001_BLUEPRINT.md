# Room 001 Blueprint — Arrival (Consent + Tempo)

## The job (locked)
Deliver **consent, safety, and tempo**. No content payload beyond conditions.
(Reference: `docs/rooms/ROOM_001_EXPLANATION.md`)

## What must change from the current draft (diagnosis)
The existing Room 001 talktrack in `data/rooms/room001_talktrack.txt` contains several Act II/III intensity cues:
- ominous “manufactured quiet”
- procedural/inspection language
- “no outside” / trap framing
- explicit “system” language
- compliance trio (“reasonable / grateful / quiet”) framed with teeth

These violate Act I: Recognition/Safety and the Non-Negotiables (no contempt, no enemies).
**We will retain only what serves consent and warmth.**

## Core emotional state
**Settling.** The reader’s body shifts from hurry → presence.

## Micro-beats (page-level)
1) Ordinary approach (nothing special)
2) Permission to stop
3) First breath cue (a pause, a quiet line)
4) A simple threshold detail (door, porch, light) that feels human
5) Gentle invitation to begin “where you are”

## Symbol use (allowed intensity)
- Door = consent (ordinary, unlocked, non-tricky)
- Quiet = rest (earned, familiar)
- Warm light = hospitality (not staging)
No mirrors, plaques, rules, “inspection,” trap doors, or authoritarian artifacts in Room 001.

## Lexicon constraints
Allowed: “You can,” “You don’t have to,” “There’s no rush,” “Right now.”
Avoid: “manufactured,” “obedient,” “inspection,” “certificate,” “compliance,” “system.”

## Rhythm recipe
- Start with 2–3 short declaratives.
- Insert the first deliberate pause as a paragraph break.
- Keep the prose plain; avoid metaphor beyond the door itself.

## Audio script design (timing)
Target: ~60–90 seconds spoken.
- 2–4 pauses of 2–4 seconds.
- One longer pause (~6 seconds) to teach that silence is safe.

## Visual + UI
- Dim warm neutral.
- Text only during narration.
- Page should feel like a hand on the shoulder, not a stage reveal.

## “Why each word” discipline (how we will draft)
Room 001 should be writable with a highlighter:
- highlight every adjective; if it adds pressure, remove it
- highlight every implied promise; if it sells the future, remove it
- highlight every authority cue; soften into choice

## Draft target (north star)
The reader finishes Room 001 thinking:
“I can stay. Nothing is being asked of me yet.”

## Handoff to Room 002
Room 002 will say (explicitly or implicitly): “This is not a test.”
Room 001 must set that up by removing performance pressure.
