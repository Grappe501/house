# Book ↔ Website Contract (v1)

The book and website serve different purposes.

## The Book
- Narrative
- Emotional
- Finite
- Readable in one sitting

## The Website
- Explanatory
- Infinite depth
- Interactive
- Monetized

## Principle
The book gestures.
The website explains.

## Reader Journey
Book → Curiosity → Website → Understanding → Action

Depth must never interrupt flow.
