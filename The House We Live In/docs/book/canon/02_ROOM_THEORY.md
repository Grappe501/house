# Room Theory

A Room equals one page.
A Room has a job.

Rooms are emotional containers, not chapters.
They regulate pacing, cognition, and nervous system load.

Room types:
- Compression (tight, focused, short)
- Flow (narrative movement)
- Expansion (space, breath, possibility)
- Silence (intentional absence)

Rooms must never multitask.
One emotional state per Room.
