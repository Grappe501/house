# Working Majority Republic — Documentation Spine (Start Here)

**Date:** 2026-01-30  
**Purpose:** This folder is the *canonical spine* for the entire project: governance model, protocol, voice, scope, and build rules.  
It is designed so we **never lose the narrative** as the website and models grow.

## How to use this folder
- Treat **`01_Vision_Guardrails.md`** as the north star.  
- Treat **`02_Book_Blueprint.md`** as the primary build artifact once book drafting begins.  
- Treat **`03_Website_Architecture.md`** as the map between book ↔ site.  
- Treat **`04_Modeling_Standards.md`** as the truth for assumptions, transparency, and model ethics.
- Treat **`05_Content_Style_Guide.md`** as the voice rules for neutral, cross-ideology communication.

## Golden Circle rule
Everything should be explainable as:
1) **WHY** it matters to an everyday working person  
2) **HOW** the system works and transitions pragmatically  
3) **WHAT** policies, institutions, and tools exist

## Key constraint
The **book** stays ideology-neutral (no labels).  
The **website** teaches ideologies as education (not identity).
