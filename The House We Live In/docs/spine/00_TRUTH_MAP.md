# 00_TRUTH_MAP  
### How This Project Is Built, Read, and Governed

This document is the **orientation map** for *The House We Live In*.

If you are reading this, you are inside the system—not encountering it from the outside. The purpose of this map is to make the structure legible so the work can be understood, extended, audited, and trusted without relying on insider knowledge or oral history.

This project is intentionally built in **three distinct but interconnected levels**. Each level serves a different cognitive and civic function. Confusion happens when those levels are mixed. Clarity comes from keeping them distinct—and deliberately linked.

---

## The Three-Level Structure

### Level 1 — The Book (The House)
**Purpose:** Emotional regulation, shared reality, agency formation  
**Primary Audience:** Humans before citizens  
**Location:** `/data/rooms/` + House Reader UI  
**Status:** Act I complete and locked (Rooms 001–025)

Level 1 is not persuasion. It is orientation.

The Book is structured as a house because houses are intuitive. People understand rooms, thresholds, windows, foundations, and load-bearing walls without needing specialized language. This allows the reader’s nervous system to regulate before analysis begins.

Each room is designed with:
- a primary emotional function
- a symbolic house element
- pacing constraints
- deferred payoffs

The Book does **not** argue policy.
It does **not** prescribe solutions.
It prepares the reader to encounter complexity without shutting down.

Act I establishes:
- regulation
- recognition
- belonging
- agency posture

Later acts will build on this foundation, but Act I is frozen to prevent emotional drift while the rest of the system is constructed.

---

### Level 2 — The Model (Doors & Pages)
**Purpose:** Conceptual clarity, comparison, explanation  
**Primary Audience:** Engaged readers, organizers, analysts  
**Location:** `/pages/`  
**Status:** Substantially built; undergoing navigation and coherence refinement

Level 2 contains the **explicit explanations**.

This is where:
- systems are named
- tradeoffs are compared
- current vs proposed structures are shown side-by-side
- transition logic is explained

If Level 1 answers *“Why does this feel wrong?”*  
Level 2 answers *“How does this actually work?”*

Navigation between Level 1 and Level 2 happens through **Doors**:
- Doors are not calls to action
- Doors are invitations to deepen understanding
- Doors always point to something concrete, inspectable, and bounded

Level 2 must remain:
- readable without Level 1 (but stronger with it)
- rigorous without becoming academic
- legible to non-experts

---

### Level 3 — Proof, Tools, and Governance
**Purpose:** Credibility, auditability, trust  
**Primary Audience:** Skeptics, funders, journalists, implementers  
**Location:** `/docs/`, `/data/`, `/tools/`  
**Status:** Active and expanding

Level 3 exists so nothing rests on vibes.

This is where:
- assumptions are listed
- sources are tracked
- uncertainty is acknowledged
- tools demonstrate mechanics
- claims can be traced back to inputs

Level 3 includes:
- registries (assumptions, sources, impacts)
- data artifacts
- tools and sliders
- workflow and completeness checks
- governance documents like this one

Importantly:
Level 3 does **not** override Levels 1 or 2.  
It supports them.

When Level 3 contradicts a claim, the claim must change.

## Canon vs Draft (Critical Distinction)

To prevent entropy, this project enforces a strict canon policy.

### Canon (Authoritative)
- `/data/rooms/` (published rooms)
- `/docs/spine/` (governance, truth map, master checklists)
- Locked acts once stamped complete

### Draft / Working
- `/plans/`
- in-progress outlines
- notes not yet promoted to spine docs

Promotion from draft → canon requires:
- explicit intent
- review for coherence
- alignment with the Truth Map

Nothing becomes “true” by accident.

## Door Philosophy

Doors are the connective tissue of the system.

A Door:
- always goes *deeper*, never sideways
- never demands belief
- never hides uncertainty
- never jumps levels without signaling the shift

Doors connect:
- emotional readiness → explanation
- explanation → proof
- understanding → agency

Door standards are defined in `docs/book/DOOR_SCHEMA.md`.

---

## Why This Structure Exists

Most political and civic projects fail for one of three reasons:
1. They overwhelm people emotionally.
2. They explain systems without preparing people to receive them.
3. They ask for trust without providing proof.

This structure exists to avoid all three.

- Level 1 stabilizes the nervous system.
- Level 2 makes systems legible.
- Level 3 earns trust through transparency.

Each level alone is insufficient.
Together, they form a system that can scale without collapsing.

## How to Use This Map

If you are:
- **Reading:** start with the House.
- **Explaining:** move between the House and Pages.
- **Questioning:** go to Proof.
- **Building:** keep the levels distinct.
- **Auditing:** follow the trails.

If you ever feel lost, return here.

This document is the contract between the work and the people who engage with it.
