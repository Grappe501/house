# Symbols, Motifs, and Why They Matter

## Rule: symbols must evolve
A symbol returns with added meaning, not repetition.

## Primary symbol set (with evolution map)

### 1) The House
**Meaning:** the operating environment (government + economy + culture + institutions)  
**Evolution:**
- Act I: lived experience and pressure
- Act II: legible structure and load paths
- Act III: repair plan and redesign
- Act IV: shared ownership and maintenance

### 2) The Weight
**Meaning:** the invisible load carried by working people  
**Evolution:** unnamed → named → redistributed → designed out where possible

### 3) Beams / Load Paths
**Meaning:** incentives; structural channels that route outcomes  
**Use:** Beam rooms should name a load path in one clean line.

### 4) Cracks
**Meaning:** predictable failure points (not moral failings)  
**Evolution:** shame → diagnosis → repair → maintenance culture

### 5) Basement
**Meaning:** hidden mechanics (finance, capture, bureaucracy)  
**Evolution:** dread → discovery → access → auditability

### 6) Attic
**Meaning:** narrative camouflage; inherited stories  
**Evolution:** myths → exposure → reframing → humility

### 7) Doors / Keys
**Meaning:** access, agency, legibility  
**Evolution:** locked → found → duplicated → shared

### 8) Thermostat (Reset)
**Meaning:** why reforms don’t stick; quiet capture  
**Evolution:** unseen → explained → constrained → stays set

### 9) Light
**Meaning:** clarity; panic drops when you can see  
**Evolution:** flicker → lamp → daylight → streetlights on the porch

### 10) Porch
**Meaning:** relational organizing; public life at human scale  
**Evolution:** nostalgia → necessity → method → civic infrastructure

## Motif list (for subtle recurrence)
- Receipts as poetry
- Hold music as oppression
- A paperclip / stapler / form number
- A single squeak in the house at night
- A cracked phone screen (access + fragility)
- A neighbor’s ladder
- A thermostat click

## Symbol placement checklist (per room)
- What symbol appears?
- What does it mean *this time*?
- How did it change since last appearance?
- Does the symbol lead to a Door Line (Level 2/3)?
